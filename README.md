# 4IK25CS223_DAV_LAB

Data Analytics and Visualization lab programs.

| Lab | Experiment | Dataset |
|-----|-----------|---------|
| lab1.py | NumPy and Pandas basics: arrays, DataFrame creation, indexing, slicing | inline |
| lab2.py | Exploratory Data Analysis: descriptive statistics, missing values, duplicates | inline |
| lab3.py | Visualization with Matplotlib/Seaborn: histogram, box, scatter, pair plot, heatmap | student_data.csv |
| lab4.py | Preprocessing: mean/median/ffill imputation, one-hot and label encoding | student_performance_dataset.csv |
| lab5.py | Outlier detection (IQR, Z-score) and treatment (removal, capping, median) | student_data.csv |
| lab6.py | Feature engineering: normalization, standardization, PCA | student_data.csv |
| lab7.py | Simple and multiple linear regression, assumption checks, R2 and RMSE | student_data.csv |
| lab8.py | Logistic regression: confusion matrix, precision, recall, F1-score | student_data.csv |
| lab9.py | Decision tree classifier: build, visualize, evaluate | student_data.csv |
| lab10.py | K-Means clustering with elbow method and cluster visualization | student_data.csv |
| lab11.py | Hierarchical clustering: dendrogram and agglomerative clustering | student_performance_dataset.csv |

Run any lab with `python labN.py` (needs numpy, pandas, matplotlib, seaborn, scipy, scikit-learn).
